# C Core Labs

A personal collection of C programming solutions built while going through university coursework (TDs/TPs) and solving logic puzzles on platforms like Exercism.

The main goal of this repo is not just to make the code work, but to write it properly—focusing on clear memory management, explicit pointer logic, and readable structure.

---

## What's Inside

* **University Coursework:** Structured solutions for academic assignments, focusing on core fundamentals and algorithm design.
* **Platform Challenges:** Problems solved from Exercism and other coding platforms to sharpen edge-case handling and logic.
* **Focus Areas:** Dynamic memory (`malloc`/`free`), custom data structures (linked lists, stacks, trees), and pointer arithmetic.
